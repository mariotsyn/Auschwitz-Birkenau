# Imágenes para la Guía Educativa Auschwitz-Birkenau

Las imágenes mostradas en esta aplicación son para propósitos estrictamente educativos.

Todas las imágenes originales pertenecen al Museo Estatal de Auschwitz-Birkenau y su uso está orientado únicamente a la educación histórica y la promoción del respeto y la memoria de las víctimas.

En un entorno de producción, se recomienda:
1. Obtener permiso oficial del Museo Estatal de Auschwitz-Birkenau para el uso de imágenes
2. Proporcionar atribuciones claras para todas las imágenes utilizadas
3. Mantener un enfoque respetuoso en la presentación del material

## Estructura de carpetas

- `/auschwitz/`: Imágenes relacionadas con Auschwitz I
- `/birkenau/`: Imágenes relacionadas con Auschwitz II-Birkenau
- `/history/`: Imágenes relacionadas con la historia del complejo
- `/common/`: Imágenes generales utilizadas en varias secciones
